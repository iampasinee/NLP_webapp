# Job Posting Data Extraction (ระบบสกัดข้อมูลประกาศรับสมัครงาน)

แอปพลิเคชันนี้พัฒนาด้วย Streamlit เพื่อสกัดข้อมูลสำคัญจากข้อความประกาศรับสมัครงาน (Job Posting) เช่น ตำแหน่งงาน, ชื่อบริษัท, เงินเดือน, ทักษะ (Skills), และสถานที่ทำงาน

## แนวคิดของ Domain
ประกาศรับสมัครงานส่วนใหญ่มักมีรูปแบบที่ไม่มีโครงสร้างชัดเจน (Unstructured Text) ระบบนี้จึงนำเทคนิค NLP มาประยุกต์ใช้ ได้แก่:
1. **Regex & Cleansing**: ลบข้อมูลที่ไม่จำเป็นออก เช่น ลิงก์เว็บไซต์ และใช้ Regex Pattern ดึงช่วงเงินเดือนออกมา
2. **Tokenization**: ตัดคำภาษาไทยด้วย PyThaiNLP เพื่อแยกองค์ประกอบของประโยค
3. **Keyword Matching & Rule-based Extraction**: จำลองการทำงานของ NER โดยใช้ Dictionary เพื่อดึงสถานที่และทักษะเฉพาะทาง รวมถึงใช้ Rule-based Regex เพื่อค้นหาชื่อบริษัทและตำแหน่ง

## วิธีใช้งาน
1. เปิด URL ของแอปพลิเคชันที่ Deploy บน Streamlit Community Cloud
2. คัดลอกข้อความประกาศรับสมัครงานไปวางในกล่องข้อความ
3. กดปุ่ม "สกัดข้อมูล (Extract)"
4. ระบบจะแสดงข้อมูลที่แยกแยะออกมาในรูปแบบที่อ่านง่าย

> "ช่วยเขียนโค้ด Streamlit Application ด้วย Python เพื่อสกัดข้อมูล ตำแหน่งงาน, ชื่อบริษัท, เงินเดือน, สกิลที่ต้องการ และสถานที่ จากข้อความประกาศรับสมัครงาน โดยบังคับให้ใช้ Regex ในการ Cleansing ข้อมูล และใช้ PyThaiNLP ในการทำ Tokenization"
