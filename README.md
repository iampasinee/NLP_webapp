## 1. แนวคิดของ Domain

หัวข้อที่เลือก: **ระบบคัดกรองรีวิวสินค้า/อาหาร**

เหตุผลที่เลือกหัวข้อนี้: รีวิวออนไลน์ (Google Maps, Facebook, Wongnai ฯลฯ) เป็นข้อมูลที่มีจำนวนมาก
และไม่มีโครงสร้าง (unstructured text) เจ้าของร้านหรือแบรนด์มักต้องอ่านรีวิวทีละข้อความเพื่อสรุปว่า
ลูกค้าพูดถึงอะไรบ้าง ระบบนี้จึงช่วย **สกัดข้อมูลสำคัญโดยอัตโนมัติ** จากรีวิวดิบ ได้แก่:

| ข้อมูลที่สกัด | คำอธิบาย |
|---|---|
| ชื่อแบรนด์/ร้าน | ชื่อร้านหรือแบรนด์ที่ถูกกล่าวถึงในรีวิว |
| ทำเล/พิกัด | ย่าน/สถานที่ตั้งของร้านที่ปรากฏในข้อความ |
| เมนู | รายการอาหาร/เครื่องดื่มที่ถูกกล่าวถึง |
| คำชม / คำติ | คำคุณศัพท์เชิงบวก/เชิงลบ พร้อมสรุปแนวโน้มความคิดเห็นโดยรวม |
| หมวดหมู่ (Topic) | จัดกลุ่มรีวิวเป็น รสชาติ/คุณภาพอาหาร, บริการ, ราคา, บรรยากาศ/ความสะอาด |

นอกจากนี้ในโหมดวิเคราะห์แบบไฟล์ (batch) ยังมี **Word Cloud** คำที่พบบ่อยในรีวิวทั้งชุด และ
**Top-N ร้าน/แบรนด์ และเมนูยอดนิยม** เพื่อสรุปภาพรวมได้เร็วขึ้น

ผลลัพธ์ที่ได้สามารถนำไปต่อยอดเป็น dashboard สรุปความพึงพอใจลูกค้า หรือระบบแจ้งเตือนรีวิวเชิงลบได้

## 2. เทคนิค NLP ที่นำมาประยุกต์ใช้

1. **Regex & Cleansing** (`clean_text`)
   - ลบลิงก์ (URL) และอิโมจิออกจากข้อความ ก่อนดึงเก็บเบอร์โทรศัพท์ที่พบแยกไว้ต่างหาก
   - ตัดอักษรซ้ำที่เกิดจากการพิมพ์เน้นอารมณ์ เช่น `อร่อยยยยย` → `อร่อยย`

2. **Tokenization & Normalization** (`tokenize_and_normalize`)
   - ใช้ `pythainlp.tokenize.word_tokenize` (engine `newmm`) ตัดคำภาษาไทยที่ไม่มีช่องว่างระหว่างคำ
   - ใช้ `pythainlp.util.normalize` เพื่อจัดรูปแบบสระ/วรรณยุกต์ให้เป็นมาตรฐานเดียวกัน
   - กรอง stopword ภาษาไทยออกด้วย `pythainlp.corpus.common.thai_stopwords`

3. **Topic Identification** (`classify_topic`)
   - จัดหมวดหมู่รีวิวแบบ keyword-based ออกเป็น 4 กลุ่ม: รสชาติ/คุณภาพอาหาร, บริการ, ราคา,
     บรรยากาศ/ความสะอาด โดยนับความถี่คำสำคัญในแต่ละหมวดแล้วเลือกหมวดที่มีคะแนนสูงสุด

4. **POS Tagging (ต่อยอดจาก NER)** (`get_pos_tags`, `extract_brand`, `extract_location`, `extract_menu`)
   - ใช้ `pythainlp.tag.pos_tag` (engine `perceptron`, corpus `orchid_ud`) ระบุชนิดคำ
     เพื่อช่วยตรวจสอบคำนามที่เป็นตัวเลือกของชื่อร้าน/เมนู
   - ใช้กติกา (rule-based) ร่วมกับคำ marker เช่น "ร้าน", "แถว", "สั่ง/กิน/ทาน" แล้วดึง
     token ที่ตามหลัง marker นั้นแบบ token-based (ไม่ใช้ regex ตรงบนสตริงดิบ เพราะภาษาไทย
     ไม่มีช่องว่างระหว่างคำ) เพื่อสกัดชื่อแบรนด์ ทำเล และเมนู
   - จัดการปัญหาคำปฏิเสธ (negation) เบื้องต้น เช่น "ไม่อร่อย" จะไม่ถูกนับเป็นคำชม
     แต่จะถูกจัดเป็นคำติแทน

5. **Word Cloud & Top-N Analytics** (`build_word_frequencies`, `render_wordcloud`, `get_top_n_from_column`)
   - รวม token จากรีวิวทั้งหมดในโหมด batch มานับความถี่ (ตัด stopword ออก) แล้วสร้าง
     Word Cloud ด้วยไลบรารี `wordcloud` โดยใช้ `generate_from_frequencies` แทนการปล่อยให้
     ไลบรารี tokenize เอง เพราะภาษาไทยไม่มีช่องว่างระหว่างคำ การ tokenize ปกติของ `wordcloud`
     (ซึ่งออกแบบมาสำหรับภาษาอังกฤษ) จะตัดคำภาษาไทยผิดตำแหน่ง — ต้องใช้ font ที่รองรับภาษาไทย
     (`fonts/NotoSansThai-Regular.ttf`) ด้วย ไม่เช่นนั้นตัวอักษรไทยจะแสดงเป็นกล่องว่าง
   - นับความถี่ของค่าในคอลัมน์ "ชื่อแบรนด์/ร้าน" และ "เมนู" จากผลลัพธ์ทั้งหมด เพื่อแสดง
     Top-N ร้าน/แบรนด์ และเมนูที่ถูกพูดถึงมากที่สุด (ปรับจำนวนอันดับได้ผ่าน slider)

## 4. วิธีใช้งาน

1. **วิเคราะห์รีวิวเดี่ยว** (แท็บ "วิเคราะห์รีวิวเดี่ยว"): พิมพ์/วางข้อความรีวิว แล้วกด "วิเคราะห์รีวิว"
   ระบบจะแสดงผลการสกัดข้อมูลทั้งหมด พร้อมรายละเอียดเชิงเทคนิค (token และ POS tag)
2. **วิเคราะห์แบบไฟล์ (batch)** (แท็บ "วิเคราะห์แบบไฟล์"): อัปโหลดไฟล์ `.txt` (1 บรรทัด = 1 รีวิว)
   หรือไฟล์ `.csv` ที่มีคอลัมน์ชื่อ `review` หรือกดใช้ไฟล์ตัวอย่าง `sample_reviews.txt` ที่แนบมาด้วย
   จากนั้นกด "ประมวลผลทั้งหมด" ระบบจะประมวลผลทุกรีวิว แสดงเป็นตาราง กราฟสรุป และปุ่มดาวน์โหลดผลลัพธ์เป็น CSV

## 6. ข้อจำกัดที่ทราบ (Known Limitations)

- การสกัดชื่อแบรนด์/ทำเล/เมนู เป็นแบบ rule-based + dictionary-based ยังไม่ใช่ NER model
  เต็มรูปแบบ จึงอาจพลาดกรณีที่ข้อความไม่มี marker คำชัดเจน (เช่น "ร้าน", "แถว", "สั่ง")
- พจนานุกรมเมนู/คำชม-คำติ/ทำเล เป็นชุดคำเริ่มต้นที่สามารถขยายเพิ่มได้ในไฟล์ `app.py`
  (ตัวแปร `MENU_DICT`, `POSITIVE_WORDS`, `NEGATIVE_WORDS`, `THAI_PROVINCES`)
- การจัดการคำปฏิเสธ (negation) รองรับเฉพาะรูปแบบพื้นฐาน (คำปฏิเสธอยู่ติดกับคำก่อนหน้าคำเป้าหมาย)
